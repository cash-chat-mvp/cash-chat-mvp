## 2. 도메인 책임

- 책임 요약: 회원 상태·제재·위험 표시·내부 메모·로그인/기기 이력을 소유하고 회원 상태 정책을 판단한다.
- 담당하는 업무: 회원 검색·상세, 제재·해제, 활동 통합 조회, 위험 표시·메모, 로그인·기기 이력, 탈퇴 처리.
- 담당하지 않는 업무: 자산 조정(보상·경제), 감사 로그 저장(감사·보안), 관리자 계정(인증·권한).
- 주요 연관 도메인: 감사·보안, 보상·경제, 어뷰징·위험 관리, 서비스 서버(제재 상태 검증).
