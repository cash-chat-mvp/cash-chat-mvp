## 2. 도메인 책임

- 책임 요약: 대화·메시지·토큰 usage·모델 단가·라우팅 정책·품질 풀 데이터를 소유하고 채팅 품질·비용 정책을 판단한다.
- 담당하는 업무: 채팅 이력, 성공·실패 분석, 토큰·비용 기록, 모델 라우팅 정책, 품질 풀 운영.
- 담당하지 않는 업무: 비용 대시보드 표출(대시보드), Energy 예약·정산 원장(보상·경제).
- 주요 연관 도메인: 대시보드, 보상·경제, 감사·보안(채팅 원문 조회 감사).
