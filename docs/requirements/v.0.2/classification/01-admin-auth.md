## 2. 도메인 책임

- 책임 요약: 관리자 계정·자격증명·세션·RBAC 데이터를 소유하고 접근 통제 정책을 판단한다.
- 담당하는 업무: 관리자 로그인, 계정 생성·비활성화, 역할·세부 권한, 세션·추가 인증.
- 담당하지 않는 업무: 서비스 회원 인증(회원·제재), 감사 로그 저장(감사·보안).
- 주요 연관 도메인: 감사·보안(모든 인증 이벤트 감사), 전 도메인(권한 검사 제공).
