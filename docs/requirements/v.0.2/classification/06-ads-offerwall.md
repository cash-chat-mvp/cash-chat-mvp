## 2. 도메인 책임

- 책임 요약: AdMob SSV 이벤트·TNK 콜백·광고 quota·노출 정책 데이터를 소유하고 광고 보상 검증 정책을 판단한다.
- 담당하는 업무: SSV 이력, 광고 시청·한도, TNK 포스트백, 운영 정책 값, 노출 관리.
- 담당하지 않는 업무: 자산 원장 반영(보상·경제), 수익 분석(마케팅·매출·정산).
- 주요 연관 도메인: 보상·경제, 대시보드, 어뷰징·위험 관리.
