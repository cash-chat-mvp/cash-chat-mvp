## 2. 도메인 책임

- 책임 요약: 감사 로그 데이터를 소유하고 불변성·원자성·위험 작업 통제 정책을 판단한다.
- 담당하는 업무: 관리자 변경 감사, 민감정보 조회 감사, 위험 작업 실행 전 확인.
- 담당하지 않는 업무: 감사 대상 업무 데이터의 소유(각 도메인), 관리자 권한 판단(인증·권한).
- 주요 연관 도메인: 변경·조회를 수행하는 모든 도메인.
