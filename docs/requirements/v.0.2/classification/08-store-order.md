## 2. 도메인 책임

- 책임 요약: 상품 카탈로그·재고·주문·인벤토리·공급업체 발송 데이터를 소유하고 판매 정책을 판단한다.
- 담당하는 업무: 상품 관리, 재고·판매 정책, 주문 조회, 주문 취소·복구, 교환 상품·발송 관리.
- 담당하지 않는 업무: 포인트 환불 원장 반영(보상·경제), 결제 감사(감사·보안).
- 주요 연관 도메인: 보상·경제, 감사·보안, 고객지원(주문 문의 연결).
