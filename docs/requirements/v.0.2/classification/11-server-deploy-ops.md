## 2. 도메인 책임

- 책임 요약: 서비스 상태·메트릭·오류 로그 조회와 승인된 배포 파이프라인 실행을 관리한다.
- 담당하는 업무: 서비스·의존성 상태 조회, 오류율·응답시간·오류 로그 조회, 배포·재기동 요청.
- 담당하지 않는 업무: 오류에 연결된 운영 데이터 소유(각 도메인), CI/CD 파이프라인 자체 구성(프로젝트 셋업).
- 주요 연관 도메인: 전 도메인(오류→운영 데이터 이동), 감사·보안(재기동 감사).
