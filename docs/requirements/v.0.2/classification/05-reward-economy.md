## 2. 도메인 책임

- 책임 요약: 포인트·Energy 지갑과 변동 원장을 소유하고 자산 조정·정합성 정책을 판단한다.
- 담당하는 업무: 원장 조회, 포인트·Energy 수동 조정, 채널별 보상 조회, 실패 보상 재처리.
- 담당하지 않는 업무: 보상 발생 원천 이벤트 소유(광고·오퍼월·리텐션 등), 감사 로그 저장(감사·보안).
- 주요 연관 도메인: 광고·오퍼월, 진화·리텐션, 채팅·AI 운영, 감사·보안, 대시보드.
