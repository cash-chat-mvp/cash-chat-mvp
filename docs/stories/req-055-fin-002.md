## Acceptance Criteria (원문 전사)

1. AC-01 Ledger 상태 명시: 휴면·미연결 상태를 명확히 표시하고 실제 수익으로 합산하지 않는다.
2. AC-02 연결 후 정산: 총수익, 위험 준비금, 서비스 준비금, 사용자 보상, 회사 이익을 반환한다.
3. AC-03 대조: 광고사 확정 리포트와 내부 지급 데이터의 차이 금액과 원인 후보를 표시한다.
