# Story: REQ-055 정산 내역 조회

Status: Draft

## Story

재무 관리자로서 수익 배분과 보상 부채를 검증하기 위해 정산 내역을 조회할 수 있다.

- 우선순위: P3
- 주 도메인: 마케팅·매출·정산
- 에픽: 마케팅·매출·정산 (v.0.2) — CC-578
- Jira 스토리: CC-636
- 원문 근거: INTAKE-001 US-ADM-FIN-002
- 기존 관계: 신규 (v.0.2)
- UI: 2단계에서 와이어프레임 작성 (docs/ux/wireframes/)

## Acceptance Criteria (원문 전사)

1. AC-01 Ledger 상태 명시: 휴면·미연결 상태를 명확히 표시하고 실제 수익으로 합산하지 않는다.
2. AC-02 연결 후 정산: 총수익, 위험 준비금, 서비스 준비금, 사용자 보상, 회사 이익을 반환한다.
3. AC-03 대조: 광고사 확정 리포트와 내부 지급 데이터의 차이 금액과 원인 후보를 표시한다.
