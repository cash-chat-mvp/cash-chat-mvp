# 대화 맥락 반영 광고 (자체/제휴 카드 + AdMob 하이브리드) — 향후 설계 필요

- 작성일: 2026-06-23
- 상태: **제안 / 보류** (백엔드 제휴 인벤토리 부재로 현 단계 미진행)
- 관련: [2026-06-23-chat-inline-native-ad-design.md](../superpowers/specs/2026-06-23-chat-inline-native-ad-design.md) (현재 진행 중인 AdMob 전용 네이티브 광고), `apps/frontend/CLAUDE.md` Epic E/F

## 배경

채팅 인라인 네이티브 광고를 설계하던 중, "광고가 채팅 내용을 어느 정도 반영하게 할 수 있나"라는 요구가 나왔다. 결론은 다음과 같다.

- **순수 AdMob 네이티브 광고로는 불가능.** 어떤 광고가 뜰지는 구글 광고 네트워크가 경매로 결정하며, 앱이 대화 주제로 특정 광고를 지정할 수 없다.
- 사용자의 **채팅 내용(사적 대화)을 광고 타게팅에 넘기는 것은 AdMob 정책 + 개인정보(GDPR/맞춤형 광고 동의) 위반 소지**가 크다.
- 따라서 "대화를 반영한 광고"는 광고 네트워크가 아니라 **자체/제휴 인벤토리를 백엔드/AI가 맥락 기반으로 선택**하는 방식으로만 가능하다.

## 현재 미진행 사유

진짜 맥락 반영(A안)을 하려면 **백엔드가 대화 주제에 맞는 제휴 상품·오퍼를 골라 내려주는 인벤토리/엔드포인트**가 필요하다. 현재 이 백엔드 인벤토리가 없으므로, 우선은 [AdMob 전용 설계](../superpowers/specs/2026-06-23-chat-inline-native-ad-design.md)만 구현한다. 본 문서는 인벤토리가 갖춰졌을 때를 위한 향후 작업 기록이다.

## 방식 비교

| 방식 | 대화 반영 | 난이도 | 비고 |
|---|---|---|---|
| A. 자체/제휴 광고 카드 (백엔드가 대화 주제로 선택) | 진짜 가능 | 중 | 토대 일부 존재(아래) — 권장 |
| B. Google Ad Manager 키-밸류 타게팅 | 부분 가능 | 높음 | GAM 계정·라인아이템 직접 운영 필요. 오버스펙 |
| C. 순수 AdMob 네이티브 | 불가 | 낮음 | **현재 진행 중인 설계.** 구글 자동 개인화만, 대화 무관 |

## 이미 존재하는 토대

- `ChatItem.ProductCards` ([shared/.../chat/model/ChatItem.kt](../../apps/frontend/shared/src/commonMain/kotlin/com/nomadclub/cashchat/shared/chat/model/ChatItem.kt)) — SSE `event: product` 페이로드로 백엔드가 내려주는 상품 카드. `ProductDto`에 `trackingUrl` 포함.
- 즉 "AI가 대화 맥락을 보고 관련 상품/오퍼를 골라 카드로 띄우는" 구조가 **이미 부분적으로 존재**한다. 제휴 광고 카드는 이 메커니즘의 확장으로 구현 가능하다.

## 향후 작업 시 설계 방향 (하이브리드)

- **맥락이 광고로 연결될 때** → 백엔드/AI가 제휴 상품·오퍼 카드(자체 인벤토리) 선택·노출 → 관련성·수익성 높음.
- **맥락이 없거나 채울 재고가 없을 때** → AdMob 네이티브 광고로 fill → 항상 수익 발생.
- 삽입 타이밍 정책은 현재 AdMob 설계의 `ChatStore` 카운팅 로직과 통합/공유.

## 선결 과제 / 리스크

- **백엔드 제휴 인벤토리·선택 API** 필요 (대화 주제 → 후보 오퍼 매칭).
- ⚠️ **LLM 비용**: 대화마다 "광고 띄울 주제인지/어떤 오퍼인지" 판단을 LLM에 맡기면 메시지당 토큰·호출이 늘어난다. 기존 응답 스트리밍 중 상품 추출에 합치면 추가 비용이 작지만, 별도 분류 단계를 두면 메시지당 추가 호출이 발생한다. 도입 시 호출 횟수·토큰 영향을 사전 산정할 것.
- **개인정보**: 제휴 카드 선택을 위해 대화를 백엔드에서 처리하는 경우에도, 외부 광고 네트워크로 원문을 넘기지 않도록 경계를 명확히 할 것.
- 제휴 트래킹/정산(예: 쿠팡 파트너스) 정책 준수.

## 결정

지금은 **C(AdMob 전용)** 으로 진행. 백엔드 제휴 인벤토리가 준비되면 본 문서를 기반으로 A(하이브리드)를 별도 스펙으로 승격한다.
