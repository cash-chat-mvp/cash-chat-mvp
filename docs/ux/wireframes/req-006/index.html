화면 목적

감사 담당자로서 개인정보 오남용 방지를 위해 민감정보 조회 이력을 확인할 수 있다.

회원정보 조회

AC-01 회원정보 조회: 이메일·로그인·기기 정보 조회 시 조회자, 대상 회원, 범위, 시각과 IP를 기록한다.

채팅 원문 조회

AC-02 채팅 원문 조회: 권한 보유자가 사유를 입력해 원문을 조회하면 사유와 조회 범위를 감사 로그에 기록한다.

다운로드

AC-03 다운로드: 개인정보 포함 파일 생성 시 검색 조건, 포함 범위와 관리자를 기록한다.

동작

회원정보 조회채팅 원문 조회다운로드
권한 없는 동작은 미노출(서버 검증 별도)
