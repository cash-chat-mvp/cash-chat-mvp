화면 목적

운영·CS 관리자로서 문의 또는 운영 대상 회원을 찾기 위해 회원 목록을 검색할 수 있다.

조건 검색

AC-01 조건 검색: ID, 이름, 이메일, 가입 유형, 상태, 가입 기간 조건을 모두 만족하는 회원을 페이징 반환한다.

기본 정보

AC-02 기본 정보: ID, 이름, 마스킹 이메일, 가입 유형, 상태, 가입일을 반환한다.

개인정보 제한

AC-03 개인정보 제한: 원문 권한이 없으면 이메일과 외부 식별자를 마스킹한다.
