화면 목적

운영 관리자로서 서비스 이상과 운영량을 빠르게 파악하기 위해 핵심 지표를 한 화면에서 조회할 수 있다.

기간 지표

AC-01 기간 지표: 오늘·주간·월간 대시보드 조회 시 신규·탈퇴 회원, 채팅, 광고 보상, 포인트·Energy, 구매 지표를 같은 기간 기준으로 반환한다.

성공·실패 구분

AC-02 성공·실패 구분: 채팅·광고·오퍼월의 요청 수와 성공·실패·거절 수를 구분한다.

상세 이동

AC-03 상세 이동: 지표 카드 선택 시 동일 기간·상태 필터가 적용된 상세 목록으로 이동한다.
