화면 목적

관리자로서 인가된 운영 시스템 접근을 위해 관리자 계정으로 로그인할 수 있다.

정상 로그인

AC-01 정상 로그인: 활성 관리자 계정이 존재할 때 올바른 아이디·비밀번호로 로그인하면 인증 세션을 발급하고 허용된 초기 화면 정보를 반환한다.

인증 실패

AC-02 인증 실패: 아이디가 없거나 비밀번호가 불일치하면 구체적 실패 원인을 노출하지 않고 동일한 실패 응답을 반환한다.

반복 실패 잠금

AC-03 반복 실패 잠금: 동일 계정 인증 실패가 정책 횟수에 도달하면 계정을 일정 시간 잠그고 시도 내역을 기록한다.

동작

정상 로그인인증 실패반복 실패 잠금
권한 없는 동작은 미노출(서버 검증 별도)
