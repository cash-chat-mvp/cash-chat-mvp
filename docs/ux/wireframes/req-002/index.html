화면 목적

슈퍼 관리자로서 운영 인력의 접근 통제를 위해 관리자 계정을 생성하고 비활성화할 수 있다.

생성

AC-01 생성: 관리자 계정 관리 권한이 있을 때 이름·로그인 ID·역할을 입력하면 중복되지 않은 계정을 생성한다.

비활성화

AC-02 비활성화: 슈퍼 관리자가 사유를 입력해 비활성화하면 모든 세션을 만료시키고 새 로그인을 차단한다.

자기 계정 보호

AC-03 자기 계정 보호: 자신의 계정 비활성화 요청은 거부한다.

동작

생성비활성화자기 계정 보호
권한 없는 동작은 미노출(서버 검증 별도)
