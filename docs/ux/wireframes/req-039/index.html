화면 목적

운영 관리자로서 성장 난이도와 보상을 조정하기 위해 진화 등급 정책을 관리할 수 있다.

등급 규칙

AC-01 등급 규칙: 필요 경험치, 기본 성공률, 실패 결과 변경 시 허용 범위와 레벨 연결을 검증한다.

적용 시점

AC-02 적용 시점: 유효 시각 도래 시 새 진화 시도부터 적용한다.

이력

AC-03 이력: 특정 시도 상세에 당시 적용 정책 버전을 표시한다.

동작

등급 규칙적용 시점이력
권한 없는 동작은 미노출(서버 검증 별도)
