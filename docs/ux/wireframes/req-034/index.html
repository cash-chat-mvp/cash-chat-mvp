화면 목적

운영 관리자로서 판매 카탈로그를 운영하기 위해 상품을 등록·수정·비활성화할 수 있다.

상품 등록

AC-01 상품 등록: 상품 코드, 이름, 설명, 이미지, 카테고리, 가격, 노출 순서를 입력하면 중복되지 않은 상품을 비활성 초안으로 생성한다.

판매 활성화

AC-02 판매 활성화: 필수 정보·재고 정책이 유효하면 서비스 카탈로그에 노출한다.

삭제 제한

AC-03 삭제 제한: 주문·인벤토리 이력이 있는 상품은 물리 삭제를 거부하고 비활성화만 허용한다.

동작

상품 등록판매 활성화삭제 제한
권한 없는 동작은 미노출(서버 검증 별도)
