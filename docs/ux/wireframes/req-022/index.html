화면 목적

운영 관리자로서 보상 채널의 정상 동작을 확인하기 위해 채널별 지급·거절 내역을 조회할 수 있다.

채널 구분

AC-01 채널 구분: 출석, 광고, 오퍼월, 채팅, 초대, 룰렛을 구분한다.

상태 검색

AC-02 상태 검색: 지급, 거절, 처리 중, 실패 상태와 기간으로 검색한다.

원본 추적

AC-03 원본 추적: 원본 이벤트부터 자산 원장까지 처리 단계를 연결한다.
