화면 목적

권한 있는 운영 관리자로서 보상 누락을 안전하게 복구하기 위해 재처리 가능한 보상을 다시 처리할 수 있다.

가능 여부

AC-01 가능 여부: 원본 유효성, 기존 지급, 멱등 키 검사 결과를 반환한다.

안전한 재처리

AC-02 안전한 재처리: 원본이 유효하고 지급 거래가 없으면 기존 비즈니스 규칙으로 한 번만 지급한다.

무효 이벤트 차단

AC-03 무효 이벤트 차단: 위조 서명, 미존재 회원, 기지급 거래는 거부하고 근거를 기록한다.

동작

가능 여부안전한 재처리무효 이벤트 차단
권한 없는 동작은 미노출(서버 검증 별도)
