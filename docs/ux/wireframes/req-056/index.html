화면 목적

운영 관리자로서 보상 손실을 줄이기 위해 비정상 적립 의심 회원을 조회할 수 있다.

규칙 탐지

AC-01 규칙 탐지: 단시간 대량 적립, 동일 기기 다계정, 반복 실패 패턴에서 규칙, 근거 이벤트, 위험 점수를 가진 후보를 생성한다.

조사 상태

AC-02 조사 상태: 정상, 조사 중, 확정 분류와 근거를 보존한다.

자동 제재 금지

AC-03 자동 제재 금지: 관리자 검토 전 자동 포인트 몰수·영구 정지를 수행하지 않는다.
