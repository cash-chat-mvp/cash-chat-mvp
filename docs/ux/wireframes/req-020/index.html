화면 목적

권한 있는 운영 관리자로서 보상 누락과 오지급을 정정하기 위해 회원의 포인트를 수동으로 지급하거나 차감할 수 있다.

지급·차감

AC-01 지급·차감: 회원, 금액, 사유, 관련 번호가 유효하면 지갑과 원장을 단일 트랜잭션으로 변경한다.

음수 방지

AC-02 음수 방지: 차감 후 잔액이 음수가 되면 거부하고 데이터를 변경하지 않는다.

멱등성

AC-03 멱등성: 동일 요청 식별자 재요청은 기존 결과를 반환하고 중복 조정하지 않는다.

동작
