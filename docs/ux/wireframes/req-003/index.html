화면 목적

슈퍼 관리자로서 업무 범위에 맞는 접근 통제를 위해 관리자 역할과 세부 권한을 관리할 수 있다.

권한 구성

AC-01 권한 구성: 역할에 조회·변경·다운로드 권한을 부여하면 다음 API 요청부터 적용한다.

서버 검증

AC-02 서버 검증: 권한 없는 관리자가 API를 직접 호출하면 `403 Forbidden`으로 거부한다.

메뉴 제한

AC-03 메뉴 제한: 로그인 시 허용된 메뉴와 동작만 노출한다.
