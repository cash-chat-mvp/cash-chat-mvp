타임라인

AC-01 타임라인: 로그인, 채팅, 자산, 광고, 출석, 오퍼월, 초대, 룰렛, 진화, 구매를 시간순 반환한다.

필터

AC-02 필터: 유형·기간 조건으로 필터링한다.

원본 연결

AC-03 원본 연결: 자산 변동 활동은 원본 이벤트, 원장 거래, 변경 후 잔액을 연결한다.
