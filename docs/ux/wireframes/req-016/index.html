화면 목적

운영 관리자로서 의심 회원의 조사 상태를 공유하기 위해 위험 표시와 내부 메모를 관리할 수 있다.

표시 등록

AC-01 표시 등록: 위험 유형, 사유, 근거 입력 시 회원 상세에 내부 위험 표시를 추가한다.

사용자 비노출

AC-02 사용자 비노출: 내부 표시와 메모를 서비스 앱에 노출하지 않는다.

해제 이력

AC-03 해제 이력: 해제 사유 입력 시 표시를 비활성화하고 과거 이력을 보존한다.

동작

표시 등록사용자 비노출해제 이력
권한 없는 동작은 미노출(서버 검증 별도)
