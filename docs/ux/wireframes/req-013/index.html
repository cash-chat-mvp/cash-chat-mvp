화면 목적

운영·CS 관리자로서 회원 상태를 종합적으로 파악하기 위해 회원 상세정보를 조회할 수 있다.

기본·자산 정보

AC-01 기본·자산 정보: 가입 정보, 상태, 포인트, 사용·예약 Energy, 진화 등급·경험치를 반환한다.

활동 요약

AC-02 활동 요약: 채팅, 광고, 출석, 오퍼월, 초대, 룰렛, 구매 누적 수를 반환한다.

미생성 데이터

AC-03 미생성 데이터: 미생성 도메인 데이터는 전체 요청 실패 없이 미생성으로 표시한다.

조회 감사

AC-04 조회 감사: 개인정보 포함 상세 조회 시 대상, 조회자, 범위, 시각을 감사한다.
