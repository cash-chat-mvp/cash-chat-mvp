화면 목적

운영·CS 관리자로서 채팅 문의의 원인을 조사하기 위해 회원의 대화와 메시지 이력을 조회할 수 있다.

대화 검색

AC-01 대화 검색: 회원, 대화 ID, 메시지 상태, 모델, 기간으로 검색해 페이징 반환한다.

메시지 상태

AC-02 메시지 상태: 역할, 상태, 모델, 발생 시각을 순서대로 반환한다.

원문 보호

AC-03 원문 보호: 채팅 원문 권한이 없으면 내용은 제외하고 운영 메타데이터만 반환한다.
