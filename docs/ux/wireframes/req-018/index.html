화면 목적

운영·CS 관리자로서 회원의 탈퇴 요청을 정책에 맞게 처리하기 위해 탈퇴 상태와 개인정보 처리 단계를 관리할 수 있다.

탈퇴 예약

AC-01 탈퇴 예약: 요청 근거와 처리 예정일 확인 시 탈퇴 예정 상태로 변경하고 활성 인증 토큰을 무효화한다.

보존 정책 적용

AC-02 보존 정책 적용: 처리일 도래 시 법적·회계 보존 대상과 즉시 삭제·익명화 대상을 구분 처리한다.

재가입 식별 정책

AC-03 재가입 식별 정책: 익명화 후 동일 OAuth·기기 재가입은 확정된 정책에 따라 허용·차단하고 과거 개인정보를 임의 복원하지 않는다.

처리 감사

AC-04 처리 감사: 상태·처리 단계 변경 시 근거, 처리자, 전후 상태, 결과를 감사 로그에 기록한다.

동작
