화면 목적

권한 있는 운영 관리자로서 반복적인 악성 이용을 차단하기 위해 기기 또는 앱 식별자를 차단할 수 있다.

차단 등록

AC-01 차단 등록: 식별자, 기간, 사유 입력 시 차단 목록에 등록하고 영향 회원을 표시한다.

서비스 적용

AC-02 서비스 적용: 차단 식별자의 신규 가입·인증 요청을 서비스 서버가 정책에 따라 거부한다.

해제·감사

AC-03 해제·감사: 과거 기록을 보존하고 변경을 감사한다.

동작

차단 등록서비스 적용해제·감사
권한 없는 동작은 미노출(서버 검증 별도)
