화면 목적

비용 등록

AC-01 비용 등록: 기간, 통화, 지출 금액 입력 또는 외부 데이터 수집 시 중복 기간·캠페인을 검증해 저장한다.

채널 구분

AC-02 채널 구분: 채널·캠페인별 지출을 원화 환산값과 함께 반환한다.

변경 이력

AC-03 변경 이력: 원본, 전후 값, 처리자, 사유를 반환한다.
