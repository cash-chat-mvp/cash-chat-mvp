## 3. 기능 범위

### 포함 (원문 인수조건 기준)

- AC-01 버전 정책: 최신·최소 지원 버전과 강제 업데이트 여부를 설정하면 앱 게이트가 플랫폼·버전별 정책을 반환한다.
- AC-02 점검 모드: 기간·안내 문구 설정 시 허용된 예외 기능 외 진입을 제한한다.
- AC-03 예약·이력: 유효 시각 도래 시 새 버전을 적용하고 이전 값을 보존한다.
