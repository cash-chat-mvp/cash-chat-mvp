# 03. 상점 — 강화재료 · 외형 · 네이버페이 교환권

> 상태: Draft (컨셉/플로우 중심)

## 1. 화면 구조

기존 `feature/shop`은 UI 스켈레톤만 존재. 카테고리 탭 형태로 확장.

```
┌─────────────────────────────────────┐
│  상점                    🪙 1,250    │
├─────────────────────────────────────┤
│  [강화재료][외형][교환권]            │  ← 세그먼트 탭
├─────────────────────────────────────┤
│  ┌─[ 강화재료 ]──────────────────┐  │
│  │ • 진화석 ×1     200코인        │  │
│  │ • 진화석 ×5    900코인 (10%↓)  │  │
│  │ • 확률 부적 +10% 500코인       │  │
│  │ • 보호권 (실패시 코인반환) 800 │  │
│  │ • 강화 패키지 (석5+부적1) 1200 │  │
│  └────────────────────────────────┘  │
└─────────────────────────────────────┘
```

## 2. 카테고리별 상세

### 2.1 강화재료 탭

| 아이템 | 효과 | 가격 (코인) | 비고 |
| ------ | ---- | ----------- | ---- |
| 진화석 | 진화 시도 1회 필요 재료 | 200 | 가장 기본 |
| 진화석 ×5 | 묶음 할인 | 900 | 10% 할인 |
| 확률 부적 | 다음 시도 성공 확률 +10%p | 500 | 1회용, Lv4 이상 시 +5%p로 감산 |
| 보호권 | 실패 시 소비 코인 50% 반환 | 800 | 1회용 |
| 강화 패키지 | 석5 + 부적1 | 1,200 | 24h 한정 노출 |

**노출 룰**
- 패키지/할인 묶음은 **시간 한정** 배지 (FOMO 유도)
- 보유 수량은 아이콘 옆에 항상 노출
- 부족 코인 시 [🪙 충전하기] → 혜택존 광고/오퍼월로 딥링크

### 2.2 외형 아이템 탭 (Phase 2 가정)

- 캐릭터 스킨, 액세서리, 배경
- 결제 수단: 코인 또는 **유료 결제(IAP)**
- Phase 1에서는 비활성 또는 "Coming Soon" 표시
- 외형 정책 미결 (고정 트리 vs 커스텀)에 따라 작업량 결정 — overview 문서 참조

### 2.3 네이버페이 교환권 탭 (핵심 변경)

코인을 **현금성 자산(네이버페이 포인트)** 으로 자동 교환.

```
┌─[ 네이버페이 교환권 ]────────────┐
│ 보유 코인: 12,500                 │
│                                    │
│ • 5,000 코인 → 네이버페이 4,500원 │
│ • 10,000 코인 → 9,500원 (할증)    │
│ • 30,000 코인 → 29,000원          │
│                                    │
│ [교환 신청]                       │
└────────────────────────────────────┘
```

**플로우 (자동발급)**

```
[유저] 교환 신청 (단위 선택)
   ↓
[Backend] voucher.requestExchange(userId, amount)
   ├─ KYC: 이메일 또는 휴대폰 인증 1회 (최초 교환 시)
   ├─ 코인 잔액 확인 + 차감 (트랜잭션)
   ├─ 일일/월간 교환 한도 체크
   ├─ 어뷰징 스코어 체크 (가입일/활동량/기기 등)
   └─ 결제 API 호출:
       (옵션 A) 네이버페이 포인트 API 직접 송금
       (옵션 B) 네이버페이 상품권 발급사 API (기프티콘식 PIN)
   ↓
[Webhook/응답] 발급 PIN 또는 송금 트랜잭션 ID 수신
   ↓
[유저] 마이페이지 > 교환 내역에서 PIN 확인 또는 즉시 충전 완료 토스트
```

**중요 결정 사항**
- 네이버페이 포인트 API는 사업자 등록 + 가맹점 심사 필요. Phase 1 MVP에는 **기프티콘식 PIN 발급(옵션 B)** 이 현실적
- 옵션 B는 외부 사업자(Giftee 등) 통한 발급. 수수료 발생 (보통 5~7%)
- 환율 가설: 1코인 = 0.9원~0.95원 (수수료 + 마진 차감)
- 최소 교환 단위: 5,000 코인 (≈ 4,500원) — **미결정**

**어뷰징 방지 (필수)**

| 방어선 | 정책 |
| ------ | ---- |
| KYC | 최초 교환 전 본인인증 1회 |
| 한도 | 일 1만원 / 월 5만원 |
| 가입 후 대기 | 가입 후 7일 경과해야 첫 교환 가능 |
| 활동 점수 | 채팅/광고시청 활동량 임계 미만 시 보류 |
| 디바이스 | 동일 디바이스에서 다중 계정 교환 차단 |
| 환수 | 사후 어뷰징 적발 시 발급 PIN 무효화 (계약상 가능 여부 확인 필요) |

### 2.4 TNK Factory와의 관계

- TNK는 **혜택존 탭** 오퍼월로 노출 (코인 적립)
- 상점은 **코인 소비**가 주력
- 즉 TNK는 적립 채널, 상점은 소비 채널 — 분리 정상

## 3. 백엔드 도메인 (개요)

- `domain/shop/`: ShopItem, Inventory, Purchase (트랜잭션)
- `domain/voucher/`: VoucherRequest, VoucherIssue, VoucherProvider (옵션 A/B 추상화)
- `domain/kyc/`: VerificationRecord
- `domain/abuse/`: AbuseScore, AbusePolicy

## 4. 미결정

- 네이버페이 연동 방식 (포인트 직접 vs 기프티콘식) — **법무/사업 컨펌 필요**
- 환율 (1코인 ↔ 원) 최종 결정
- 최소 교환 단위
- 외형 아이템 Phase 2 도입 시기
- 강화 패키지의 한정 노출 정책 (24h, 주간 등)

## 5. 우선순위 (구현 순서 권장)

1. 강화재료 탭 (Chat 강화 시스템과 직결, MVP 필수)
2. 인벤토리/구매 트랜잭션 인프라
3. 네이버페이 교환권 (KYC + 어뷰징 인프라 동반)
4. 외형 아이템 (Phase 2)
