# Cash Chat 기획 개정 — 개요

> 작성일: 2026-05-17
> 상태: Draft (컨셉/플로우 중심)

## 1. 배경

기존 Cash Chat MVP는 "AI 채팅 + 리워드/상점"의 단순 구조였다. Confluence 「비용 산출 관련, AI 챗봇 기획 아이디어」(FCTC 스페이스, page 14975038)에 따라 다음 방향으로 개정한다.

- AI를 **육성형 캐릭터**로 시각화하고, 채팅 + 진화(강화) 게임 사이클로 리텐션 확보
- **큰수의 법칙(LLN)** 기반으로 광고 수익이 LLM API 비용을 항상 상회하도록 설계
- 단순 채팅을 넘어, **쿠팡 파트너스 큐레이션**을 자연스럽게 끼워 추가 수익화

## 2. 현행 분석 (2026-05-17 기준)

### 2.1 Frontend
- 탭 구조: 현재 2탭 (Chat / Rewards·Shop·MyPage 번들). NavigationBar는 Material3
- `feature/chat`: ChatScreen + ChatViewModel (메시지 송수신 시뮬레이션, 1.5s 딜레이)
- `feature/rewards`, `feature/shop`: UI 스켈레톤만 존재
- 광고 SDK: AdMob `play-services-ads` 의존성만 선언. **실제 통합/노출 코드 없음**
- KMM `shared/chat/`: ChatStore, ChatMessage, AdInfo 모델 정의됨
- `shared/points/PointsStore.kt`: 포인트 + 메시지 카운트 상태 존재 (광고 트리거에 활용 가능)

### 2.2 Backend
- `domain/chat/`: ChatService + LlmProvider 인터페이스. dev=Gemini, prod=OpenAI
- 스트리밍 응답 지원 (`Flux<String>`)
- `domain/point/`: UserPointService 존재
- 진화/강화/광고 보상/쿠팡 큐레이션 관련 도메인은 **전무**

### 2.3 Gap (이번 기획에서 신설/확장 필요한 것)
| 영역 | 신설/확장 |
| --- | --- |
| Frontend | 강화/진화 서브 화면, 광고 노출 로직, 쿠팡 상품 카드 컴포넌트, 혜택존(오퍼월 + 출석체크), 상점(아이템 + 교환권) |
| Backend | `domain/evolution`, `domain/ad`, `domain/coupang`, `domain/attendance`, `domain/voucher` |
| 외부 연동 | TNK Factory (오퍼월), 쿠팡 파트너스 API, 네이버페이 포인트 교환 API, AdMob 리워드/네이티브 |

## 3. 개정 IA (정보 구조)

기존 5탭 후보(Chat/Rewards/Shop/MyPage/+α) 중 **Chat 1탭에 진화 서브 화면을 포함**하는 방향으로 결정. 사용자가 답한 옵션(Chat 탭 내부 서브 화면)을 따른다.

```
┌────────────────────────────────────────────────────┐
│ BottomNav: [Chat] [혜택존] [상점] [마이]               │
└────────────────────────────────────────────────────┘

[Chat 탭]
 ├─ 메인 대화 화면 (캐릭터 헤더 + 메시지 리스트 + 입력)
 │   └─ 캐릭터 헤더 탭 → 진화/강화 서브 화면 (모달 또는 풀스크린)
 │       ├─ 현재 단계/경험치/코인
 │       ├─ 진화 시도 (슬롯/룰렛 애니메이션)
 │       └─ 외형 변화 미리보기
 │
 ├─ 메시지 사이 InlineAd (네이티브) — N메시지마다
 └─ 코인 부족 시 → [혜택존] 또는 광고 시청 유도

[혜택존 탭]
 ├─ 일일 출석체크 위젯 (상단 고정)
 ├─ TNK Factory 오퍼월 (메인)
 ├─ 추가 미션 (친구 초대, 채팅 N회 등)
 └─ 리워드 광고 (수동 트리거)

[상점 탭]
 ├─ 강화재료 (진화석/보호권/확률 부적)
 ├─ 외형 아이템 (스킨/액세서리) — Phase 2
 └─ 네이버페이 교환권 (자동발급)

[마이 탭]
 └─ 기존 유지 (설정, 로그아웃 등)
```

## 4. 핵심 수익 사이클 (요약)

```
[광고 수익 유입]                            [API 비용 유출]
 ├─ 채팅 중 네이티브 광고 (자동)         ┌── 진화 단계별 모델 라우팅
 ├─ 리워드 광고 시청 (코인 보상)         │    Lv1: mini 100%
 ├─ TNK 오퍼월 (CPI 보상)               │    Lv3: mini 80% + premium 20%
 ├─ 출석체크 (소량 코인)                 │    Lv5: mini 20% + premium 80%
 │                                       │
 └─ 진화 실패 시 코인 소각  ────────────┘   (코인 소각 = 광고 수익 잠금)
```

LLN 적용: 진화 확률을 역산해, 유저가 Lv5(고비용)에 도달하기 *전에* 평균 N회의 광고 시청을 강제하도록 설계.

## 6. 이번 기획에서 결정한 것 / 미결정

### 결정
- 강화 시스템은 Chat 탭 내부 서브 화면으로 진입 (별도 탭 신설하지 않음)
- 광고는 네이티브(상시) + 리워드(자발) + 인터스티셜(전환 지점) 3종 혼합
- 쿠팡 큐레이션은 AI 답변 트리거 기반 (모든 메시지가 아님)
- **캐릭터 외형**: AI 이미지 생성 기반 **페르소나 슬롯 (옵션 C) + 액세서리 오버레이 (옵션 A)** 하이브리드 — 상세는 [01-ai-chat.md §1.4](./01-ai-chat.md) 참조

### 미결정 (별도 의사결정 필요)
- 네이버페이 교환권 최소 교환 단위 (5,000원? 10,000원?)
- 진화 단계 수 (5단계? 10단계?) — 본 기획서는 5단계 가정
- 캐릭터 외형 생성 도구 (Midjourney / Stable Diffusion+IP-Adapter / Flux) — Phase 1 PoC로 결정
