## 0. 배경 및 목표

기존 Cash Chat은 "AI 채팅 + 다마고치 캐릭터 성장"이 핵심이다.
여기에 **비전공자 친화적 생활금융 채팅 모듈**을 얹어 다음 두 가지를 달성한다.

1. **리텐션 강화**: 매일 쓸 이유를 만든다 (주식 오늘의 이슈, 가계부 체크 등)
2. **수익화 레이어 확장**: 고급 기능을 레벨 또는 구독으로 잠가 진화 동기 강화

**설계 원칙**: 전문용어 배제, 채팅 한 줄로 결과 확인, 외부 API/MCP 기반으로 실시간 데이터 제공

## 2. 모듈 A — 주식 테마

### A-1. 오늘의 증시 브리핑
- **한 줄 설명**: 코스피·코스닥 흐름 + 주요 이슈 3개를 캐릭터 말투로 전달
- **레벨**: 무료 개방 (앱 진입 기능)
- **API**: 네이버금융 RSS, 뉴스 요약 LLM
- **Phase**: 1
- **예시 UX**:
  ```
  유저: "오늘 주식 이슈 뭐야?"
  AI: 📰 오늘 코스피 -0.8% / 코스닥 -1.2%
      1. 연준 금리 동결 → 반도체 강세
      2. 중국 경기 우려 → 철강 약세
      3. 삼성 신제품 발표 → +2.1%
      🐣 미래: "반도체는 웃고 철강은 울었어 😊"
  ```
- **미결정**: 데이터 갱신 주기 (실시간 vs 30분 캐시)

---

### A-2. 내 포트폴리오
- **한 줄 설명**: 종목·수량·평단가 입력 → 실시간 평가손익 계산
- **레벨**: Lv 2
- **API**: KIS API (한국투자증권) / 네이버금융 시세
- **Phase**: 1 (수동 입력), Phase 2 (KIS 실계좌 연동)
- **예시 UX**:
  ```
  유저: "내 주식 지금 얼마야?"
  AI: 💼 내 포트폴리오
      삼성전자 10주  +2.1%  +₩14,200
      카카오    5주  -1.3%  -₩4,600
      ────────────────
      총 평가손익: +₩9,600 (+0.5%)
  ```
- **Phase 1 구현 방식**: "삼성전자 10주 추가해줘" → DB 저장 → 공개 시세 API로 계산
- **미결정**: KIS API 서비스 계정 운영 방식 (개인 계좌 기반 이슈)

---

### A-3. 주간 예측 리포트
- **한 줄 설명**: 월요일에 내 예측 입력 → 금요일에 실제 흐름과 대조 분석
- **레벨**: Lv 3
- **API**: LLM + 주간 시세 데이터
- **Phase**: 2
- **핵심 차별점**: 증권사 앱은 시세를 보여주지만, 내 예측 vs 실제 비교는 없음
- **예시 UX**:
  ```
  [월요일] 유저: "이번 주 반도체 오를 것 같고, 환율은 1400 갈 것 같아"
  [금요일] AI: 📊 이번 주 예측 결과
      반도체: ✅ 맞음 (실제 +3.2%)
      환율:   ❌ 틀림 (1,382원으로 하락)
      누적 기록: 반도체 4주 연속 정확, 환율은 3/5
      🐣 "너 반도체 감각 진짜 좋은데? 환율은 조금 더 공부해봐!"
  ```
- **파생 기능**: 예측 정확도 누적 → "투자 인사이트 점수" → 캐릭터 EXP 연동 가능
- **미결정**: 예측 입력 포맷 (자유 텍스트 vs 구조화 폼)

---

### A-4. AI 주식 의견 분석
- **한 줄 설명**: "삼성 살까?" 내 생각 입력 → 현재 시장흐름과 대조 분석
- **레벨**: Lv 3
- **API**: LLM + 실시간 뉴스 컨텍스트
- **Phase**: 2
- **예시 UX**:
  ```
  유저: "반도체 업황 회복세라 삼성 더 살까 고민이야"
  AI: 🤔 네 생각 vs 시장
      네 예상: 반도체 회복세 → 삼성 매수
      시장:   HBM 수요 급증 ✅ / 주가 52주 고점-5% (단기 조정 주의)
      결론: 중장기 방향은 맞는데, 단기 타이밍 주의
      ⚠️ AI 의견이야, 투자는 네가 결정해!
  ```
- **면책 고지**: 투자 권유가 아님을 모든 응답 하단에 명시 (법적 요건)

---

### A-5. 투자 일기
- **한 줄 설명**: 매수·매도 이유를 기록 → AI가 나의 투자 패턴 분석
- **레벨**: Lv 4
- **API**: LLM 분석
- **Phase**: 2
- **예시 UX**:
  ```
  유저: "오늘 카카오 50주 샀어. 실적 개선 기대하고"
  AI: 📔 투자 일기 저장!
      카카오 / 매수 50주 / 이유: 실적 개선 기대
      [3개월 후] "카카오 매수 이유가 실적이었는데, 실제로 실적 +15% 나왔어. 네 판단 맞았어! ✅"
  ```
- **누적 가치**: 내 투자 근거가 얼마나 실제 결과와 맞았는지 장기 트래킹

---

### A-6. 실시간 시세 알림
- **한 줄 설명**: 목표가 도달 시 푸시 알림 발송
- **레벨**: Lv 4
- **API**: KIS API WebSocket / Firebase Cloud Messaging
- **Phase**: 3
- **예시 UX**:
  ```
  유저: "삼성전자 8만원 되면 알려줘"
  AI: ✅ 알림 설정! 8만원 도달 시 푸시 드릴게요
  [도달 시] 푸시: "🔔 삼성전자 목표가 도달! 현재 80,100원"
  ```

## 3. 모듈 B — 생활가계부

### B-1. 채팅 가계부
- **한 줄 설명**: "점심 파스타 15000원" 입력 → AI 자동 카테고리 분류·저장
- **레벨**: 무료 개방
- **API**: LLM 자연어 파싱
- **Phase**: 1
- **예시 UX**:
  ```
  유저: "점심 파스타 먹었어 15000원"
  AI: ✅ 기록!
      🍝 식비 ₩15,000 / 오늘 점심
      이번달 식비: ₩187,000 / 목표 ₩300,000 (62%)
  ```
- **지원 표현 예시**: "편의점 5300", "택시 12000", "넷플릭스 17000 자동결제"

---

### B-2. 영수증 OCR
- **한 줄 설명**: 영수증 사진 한 장 → 아이템별 자동 가계부 등록
- **레벨**: Lv 2
- **API**: Google ML Kit (온디바이스, 무료)
- **Phase**: 1
- **예시 UX**:
  ```
  유저: [영수증 사진 업로드]
  AI: 📷 인식 완료!
      GS25 편의점
      • 삼각김밥    ₩1,500
      • 아이스아메리카노 ₩2,000
      합계 ₩5,300 / 편의점·식비로 저장할까?
      [✅ 저장] [✏️ 수정]
  ```
- **구현 포인트**: 온디바이스 OCR이라 서버 비용 없음, 개인정보 안전

---

### B-3. 월간 지출 리포트
- **한 줄 설명**: 카테고리별 지출 비율·트렌드·AI 절약 팁 제공
- **레벨**: 무료 개방
- **API**: 내부 DB 집계
- **Phase**: 1
- **예시 UX**:
  ```
  유저: "지난달 지출 분석해줘"
  AI: 📊 5월 리포트
      식비    ₩287,000  35%
      쇼핑    ₩215,000  26%  ← 지난달 대비 +₩82,000
      교통비  ₩98,000   12%
      합계    ₩816,000
      💡 쇼핑이 많이 늘었어! 이번달 ₩150,000으로 목표 잡아볼까?
  ```

---

### B-4. 구독 서비스 관리
- **한 줄 설명**: 넷플릭스·유튜브 등 자동결제 현황 한눈에 정리
- **레벨**: Lv 2
- **API**: 수동 입력 (Phase 1) / 오픈뱅킹 자동 감지 (Phase 3)
- **Phase**: 1
- **기획 배경**: 20-30대 중 자신이 매달 얼마를 구독에 쓰는지 모르는 경우가 많음
- **예시 UX**:
  ```
  유저: "이번달 자동결제 뭐 나가?"
  AI: 💳 이번달 구독 서비스
      넷플릭스   ₩17,000  매월 15일
      유튜브     ₩14,900  매월 3일
      애플뮤직   ₩8,900   매월 22일
      ─────────────────
      월 구독 합계: ₩40,800
      🐣 "생각보다 많지? 안 보는 거 정리해볼까?"
  ```

---

### B-5. 저축 목표 챌린지
- **한 줄 설명**: "3개월 100만원" 설정 → 주간 체크인 + EXP 보상 연동
- **레벨**: Lv 3
- **API**: 내부 DB + 캐릭터 EXP 연동
- **Phase**: 2
- **예시 UX**:
  ```
  유저: "3개월 안에 100만원 모으고 싶어"
  AI: 🎯 저축 챌린지 시작!
      목표: ₩1,000,000 / 90일
      매일 ₩11,112씩 모으면 돼
      달성 시 캐릭터 EXP +500 특별 보상 🎁
      [시작하기]
  ```
- **레벨 연동 포인트**: 저축 목표 달성 → 진화 EXP 보상 → 진화 동기 강화

---

### B-6. 오픈뱅킹 자동 연동
- **한 줄 설명**: 계좌 입출금 자동으로 가져와 가계부 자동화
- **레벨**: Lv 5 / 구독 전용
- **API**: 금융결제원 오픈뱅킹 API
- **Phase**: 3
- **주의사항**: 금융결제원 심사 필요 (사업자 등록 + 정보보호 요건)
- **미결정**: 오픈뱅킹만으로 충분한지 vs 마이데이터 라이선스 취득 검토

## 4. 모듈 C — 생활밀착 기능

### C-1. 환율 계산기
- **한 줄 설명**: "일본 여행 30만엔 한국돈으로?" 즉시 답변
- **레벨**: 무료 개방 (앱 진입 기능)
- **API**: 한국은행 Open API (무료)
- **Phase**: 1
- **예시 UX**:
  ```
  유저: "일본 여행 30만엔이면 한국 돈으로 얼마야?"
  AI: 오늘 환율 기준 ₩2,730,000 정도야! (100엔=910원)
      작년 이맘때보다 엔화 3% 싸졌어서 지금 바꾸는 게 나을 수도 있어 💱
  ```

---

### C-2. 예금·적금 비교
- **한 줄 설명**: "500만원 1년 굴릴 곳" → 금리 높은 상품 추천
- **레벨**: Lv 2
- **API**: 금융감독원 금융상품통합비교공시 API (공개 무료)
- **Phase**: 1
- **예시 UX**:
  ```
  유저: "500만원 1년 굴릴 곳 추천해줘"
  AI: 지금 기준 좋은 상품들:
      🏦 토스뱅크 파킹통장  연 4.0%  이자 ₩200,000
      🏦 케이뱅크 적금      연 5.2%  이자 ₩260,000
      🏦 SBI저축은행        연 5.5%  이자 ₩275,000
  ```

---

### C-3. 금융 퀴즈
- **한 줄 설명**: 데일리 퀴즈 맞추면 코인 보상 → 데일리 미션 연동
- **레벨**: 무료 개방
- **API**: 퀴즈 DB (LLM으로 자동 생성·검수)
- **Phase**: 1
- **예시 UX**:
  ```
  오늘의 퀴즈: PER이 낮을수록?
  ① 주가가 비싸다
  ② 이익 대비 주가가 저렴하다 ← 정답
  ③ 기업이 적자다
  ✅ 정답! 🪙+20코인
  🐣 "PER 낮으면 숨겨진 가치주일 수 있어!"
  ```
- **데일리 미션 연동**: "금융 퀴즈 1회 맞추기" 미션으로 추가

---

### C-4. 세금 계산기
- **한 줄 설명**: "연봉 4000이면 세금 얼마?" + 절세 팁 안내
- **레벨**: Lv 3
- **API**: 세율 테이블 + LLM
- **Phase**: 2
- **예시 UX**:
  ```
  유저: "연봉 4000이면 세금 얼마 내?"
  AI: 4,000만원 기준 예상 소득세 약 ₩2,640,000/년
      체크카드 더 쓰면 환급 늘릴 수 있어!
      체크카드 공제율이 신용카드(15%)보다 높아 (30%) 😊
  ```
- **시즌 이벤트**: 1월 연말정산 시즌에 특별 프로모션 연계 가능

## 10. 미결정 사항

- **캐릭터 말투 가이드**: 금융 전문 용어를 캐릭터가 어떻게 쉽게 풀어 말할지 프롬프트 가이드 필요
- **투자 면책 고지 UX**: 법적 고지를 채팅 흐름에서 어떻게 자연스럽게 처리할지
- **KIS API 계정 이슈**: 개인 계좌 기반이라 서비스 운영 방식 법무 검토 필요
- **당근마켓 크롤링 리스크**: 공식 API 없음, 크롤링 법적 리스크 확인 필요
- **퀴즈 콘텐츠 저작권**: LLM 자동 생성 퀴즈의 법적 리스크
- **레벨 잠금 수치 밸런스**: 기존 진화 확률 테이블과 맞는지 시뮬레이션 필요
- **마이데이터 전략**: 오픈뱅킹 범위 내에서 충분한지, 라이선스 취득 시기
