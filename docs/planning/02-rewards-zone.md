## 2. 컴포넌트별 상세

### 2.1 출석체크

**플로우**
```
오늘자 도장 미찍음
  ↓
[출석 도장 찍기] 탭
  ↓
백엔드: attendance.checkIn(userId, today)
  ├─ 중복 체크 (이미 찍었으면 reject)
  ├─ 연속 출석 카운트 증감
  └─ 보상 지급 (코인 + 옵션 진화석)
  ↓
도장 애니메이션 + 보상 토스트
```

**보상 테이블 (가설)**

| 누적 일차 | 코인 | 보너스 |
| --------- | ---- | ------ |
| 1~6일     | +20  | -      |
| 7일       | +50  | 진화석 1개 |
| 14일      | +100 | 진화석 2개 + 확률 부적 1 |
| 30일      | +300 | 보호권 1개 |
| 31일+     | 1~6일 사이클 재진입 (월간) |

**룰**
- 연속 출석 끊김 시 1일차로 리셋
- 모든 보상은 KST 자정 기준
- 광고 시청 시 "도장 회복권" 1회 사용 가능 (월 1회)

### 2.2 데일리 미션

**제공 미션 풀 (랜덤 3개 선택)**
- 채팅 N회 보내기
- 친구 초대 (Deep Link)
- 진화 시도 N회
- 상점 방문
- 리워드 광고 N회 시청
- 쿠팡 카드 1회 클릭

**리프레시**
- KST 자정 자동 갱신
- 광고 시청으로 "미션 새로고침권" 1회/일

### 2.3 리워드 광고 영역

Chat 탭에도 있지만, 혜택존에서는 **목록형 UI로 명시적 노출**.
- 일일 캡 (예: 10회)
- 시청 시 30~50 코인
- SSV 콜백 통과해야만 지급 (Chat 탭과 동일 정책)

### 2.4 TNK Factory 오퍼월

**연동 방식**
- TNK SDK (Android Native) 통합. iOS 미지원 시 WebView 폴백 검토
- KMM `shared`에 추상화 인터페이스 두고 androidMain에서 SDK, iosMain은 WebView wrap
- 사용자 식별: TNK `setUserName(userId)` (유저 익명 ID 사용 권장)

**노출 정책**
- 임베드 컨테이너 형식 (탭 하단)
- 또는 풀스크린 진입 옵션 (`혜택존 더보기` 버튼)
- TNK 콜백 → 백엔드 webhook → 코인 적립

**유의사항**
- TNK는 자체적으로 광고 정책/심사를 거치는 별도 광고임 — AdMob/리워드와 **중복 시청 가능**
- 어뷰징 방지: TNK 콜백 시그니처 검증 필수

## 3. 백엔드 도메인 (개요)

- `domain/attendance/`: AttendanceLog, AttendanceReward
- `domain/mission/`: MissionTemplate, UserMission, MissionProgress
- `domain/offerwall/`: TnkCallback, OfferwallReward (webhook 처리)
- 공통: `domain/point/`에 보상 지급 트랜잭션 통합 (현재 `UserPointService` 확장)

## 4. 광고 다중 채널 정리

이번 기획에서 도입되는 광고/오퍼월 채널 정리:

| 채널 | 위치 | 보상 책임 |
| ---- | ---- | --------- |
| AdMob Native | Chat 탭 인라인 | 없음 (패시브) |
| AdMob Rewarded | Chat 헤더, 혜택존 | 백엔드 (SSV) |
| AdMob Interstitial | 진화 결과 직전, 채팅 종료 | 없음 |
| TNK Factory 오퍼월 | 혜택존 | 백엔드 (webhook) |
| 출석/미션 (자체) | 혜택존 | 백엔드 |

## 5. 미결정

- TNK 외 추가 오퍼월 (Buzzvil, AdiSON 등) 도입 여부 — Phase 2 검토
- 친구 초대 보상 어뷰징 방지 정책 (디바이스 핑거프린팅?)
- 출석체크 보상 코인 ↔ 광고 시청 보상 코인 환산비 (현재 출석 20코인 ≈ 리워드 1회 절반)

## 6. 우선순위 (구현 순서 권장)

1. 출석체크 (가장 단순, 리텐션 효과 高)
2. 리워드 광고 영역 (Chat 탭과 SSV 인프라 공유)
3. 데일리 미션 (포인트/이벤트 트랙 인프라 필요)
4. TNK 오퍼월 (외부 SDK + 정산, 가장 작업량 大)
