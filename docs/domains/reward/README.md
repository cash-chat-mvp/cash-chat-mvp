# reward 도메인 — 유저 스토리 인덱스

혜택존(코인/밥 적립 채널)의 유저 스토리 카탈로그. 각 파일은 **직군 중립 계약**(스토리 + 인수 조건)이며, 완료 판정·검증의 기준선이다.

> 파일명 = 불변 ID(`US-REWARD-NNN`) + slug. 번호는 **생성 순서일 뿐 의미 없음**(우선순위/순서 아님, 재사용·재배치 안 함).
