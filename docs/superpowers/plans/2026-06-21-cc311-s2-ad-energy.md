# CC-311 S2 — Ad/Attendance → Energy (보상 재화 교체) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 광고 보상·출석 보상의 지급 재화를 포인트에서 Energy로 교체하고, 적립 시점에 지갑을 lazy 생성하며, `economy/me`에 광고 일일한도를 노출한다.

**Architecture:** 기존 `AdRewardService.grantFromCallback`·`AttendanceService.checkIn`의 **적립 호출부 한 곳만** `UserPointService.recordTransaction(...)` → `EnergyService.grant(...)`로 교체한다. SSV 서명검증·nonce·일일한도·서명로직, 그리고 로그인/인증은 일절 변경하지 않는다. 인증 코드를 못 건드리므로 지갑 행은 `EnergyService.grant` 진입 시 멱등 INSERT(`insertIfAbsent`)로 lazy 생성한다.

**Tech Stack:** Kotlin 1.9.25, Spring Boot 3.5.11, JPA(`ddl-auto: validate`), Flyway, Kotest FunSpec + TestContainers(MySQL 8.4) + mockito-kotlin.

## Global Constraints

이 절은 모든 Task의 요구사항에 암묵적으로 포함된다. 정확한 값은 verbatim이다.

- **광고 SSV·nonce·일일한도·서명 로직 절대 불변** — 보상 지급 결과(재화)만 포인트→Energy로 교체한다. (유저 지시: "기존에있는 광고확인하고 하는건 건드리지말고 포인트 주고 이부분만 건드려") 즉 `GoogleAdSsv*`, `AdRewardNonce*`, `AdRewardDailyQuota*`, `grantFromCallback`의 nonce/quota/event 상태머신 로직은 그대로 둔다.
- **로그인/인증 불변** — `domain/auth/`, JWT 필터, `SecurityConfig`를 손대지 않는다. `AuthService`에 지갑 초기화를 추가하지 않는다. 모든 재화는 `userId` 귀속. (유저 지시: "아 로그인 부분도 건드리지마")
- **내부 원가/마진 수치 비공개** — 소스·커밋 문서에 하드코딩 금지. 비민감 운영값만 `EconomyProperties`에 둔다(이미 존재).
- **Cap 초과 정책 = 거부(현행 throw 유지)** — `UserWallet.grantEnergy`는 `MAX_ENERGY` 초과 시 `EnergyCapExceededException`을 던진다. 이 동작과 `UserWallet`/`grantEnergy`를 변경하지 않는다. 광고/출석 적립이 cap을 넘기면 트랜잭션이 롤백된다(이벤트는 GRANTED로 종결되지 않음 → AdMob 재전송 시 재시도).
- **출석 Energy 지급량 = 고정 `economyProperties.attendanceEnergyReward`(기본 4)** — 기존 일차별 `reward.coin` 테이블값은 Energy 지급량으로 쓰지 않는다. `reward.coin`/`RewardView`/`nextReward(Preview)`는 보너스 아이템 정의 및 미리보기 용도로만 그대로 유지한다(의도적 최소 변경).
- **광고 Energy 지급량 = `economyProperties.rewardedEnergyPerAd`(기본 3)**, 만료 = `now + adEnergyExpirationDays`(기본 30일).
- **출석 Energy 만료 = `today + attendanceEnergyExpirationDays`(기본 7일).**
- **멱등 키 기존 패턴 유지** — 광고 `admob:reward:{transactionId}`, 출석 `attendance:{userId}:{date}`. 원장 `uq_wallet_ledger_idempotency_key`가 최종 방어선.
- **`EnergyService.grant` 시그니처(S1 확정, 불변):** `grant(userId: Long, amount: Long, sourceType: EnergySourceType, expiresAt: Instant, idempotencyKey: String): WalletLedger` — `@Transactional`.

- [ ] **Step 4: `WalletService.ensureForUpdate` 추가** — `getForUpdate`(MANDATORY, 부재 시 throw)는 그대로 두고, 멱등 생성+락 메서드를 신설한다.

```kotlin
@Transactional(propagation = Propagation.MANDATORY)
fun ensureForUpdate(userId: Long): UserWallet {
    userWalletRepository.insertIfAbsent(userId)
    return userWalletRepository.findByUserIdForUpdate(userId)
        ?: throw WalletNotInitializedException(userId)
}
```

```kotlin
// import: com.wnl.cashchat.api.domain.ad.service.AdRewardService
class EconomyController(
    private val walletService: WalletService,
    private val economyProperties: EconomyProperties,
    private val adRewardService: AdRewardService,
) {
    @GetMapping("/me")
    fun me(authentication: Authentication): EconomySnapshotResponse {
        val userId = authentication.userId()
        val now = Instant.now()
        val w = walletService.snapshot(userId)
        val quota = adRewardService.quotaOf(userId, now)
        return EconomySnapshotResponse(
            serverTime = now,
            energy = EconomySnapshotResponse.EnergyView(w.energyAvailable, w.energyReserved, economyProperties.maxEnergy),
            point = EconomySnapshotResponse.PointView(w.pendingCashablePt, w.confirmedCashablePt),
            evolution = EconomySnapshotResponse.EvolutionView(w.evolutionLevel, w.evolutionExp, w.evolutionFailStack),
            ad = EconomySnapshotResponse.AdView(quota.usedToday, quota.dailyLimit, quota.remaining, quota.resetAtKst),
            features = EconomySnapshotResponse.FeaturesView(
                rewardChatEnabled = economyProperties.rewardChatEnabled,
                rewardedAdEnabled = economyProperties.rewardedAdEnabled,
                attendanceRewardEnabled = economyProperties.attendanceRewardEnabled,
                evolutionEnabled = economyProperties.evolutionEnabled,
                cashoutEnabled = economyProperties.cashoutEnabled,
            ),
        )
    }
    // policy(), userId() 불변
}
```
